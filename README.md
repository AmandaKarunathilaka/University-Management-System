# University-Management-System
This is a University Management System built using Java Swing for the GUI and Object-Oriented Programming (OOP) concepts for backend logic.
The system provides role-based access for Admin, Student, and Lecturer, supporting key academic and administrative operations.

🚀 Key Features

👨‍💼 Admin Module

 1. Manage Students, Lecturers, Faculties, Departments, and Courses.

 2. CRUD operations (Create, Read, Update, Delete) with validation.

 3. Auto-generate username and password for each new user.
    

🎓 Student Module

 1. Course Enrollment: Students can register for courses offered by their faculty.

 2. Grade View: Students can check their academic performance securely.

 3. User login with system-generated credentials.
    

👩‍🏫 Lecturer Module

 1. Grade Management: Add and update student grades.

 2. Leave Requests: Submit leave requests to the admin.

 3. Role-based login for lecturers.
    

🏗️ OOP Concepts Applied

The project is designed around all 4 pillars of OOP:

    Encapsulation → Private fields with getters/setters for secure data handling.

    Inheritance → Common base classes (e.g., User) extended by Admin, Student, and Lecturer.

    Polymorphism → Method overriding for role-specific functionalities.

    Abstraction → Interfaces and abstract classes to define general behaviors 


**Technologies Used**

 1. Java

 2. Swing Framework (GUI development)

 3. MVC Pattern (Model–View–Controller separation)

 4. MySQL Database


🔑 Characteristics

  1. Role-based access for Admin, Student, and Lecturer.

  2. Auto-generated credentials for secure user login.

  3. Scalable design following MVC and OOP best practices.

  4. Interactive GUI with Java Swing components.
